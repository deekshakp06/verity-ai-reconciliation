How it decides
  1. Read the columns. Maps unfamiliar column names itself.
  2. Pick the method. Exact Gross − Fee − Tax = Net if a fee breakdown exists, otherwise confidence-scored matching on reference, amount and date.
  3. Refuse to guess. Wrong reference, duplicate, or a gap it can't explain goes to Exceptions with a reason.
  4. Explain and log. Each exception gets a plain-English explanation and an audit-log entry.
